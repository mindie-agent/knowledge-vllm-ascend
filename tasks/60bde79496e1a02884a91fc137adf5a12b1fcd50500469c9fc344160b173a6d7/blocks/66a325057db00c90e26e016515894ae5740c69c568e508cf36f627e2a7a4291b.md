- `max_model_len: 2048 → 1024`。

### 8 卡部分怎么处理

两个真实 checkpoint 分别约 376.99 GiB 和 405.75 GiB；GLM 在 TP8 时每 rank 已加载约 48 GiB，单次加载就需要 259–508s。改成 TP4 后，即使显存允许，真实权重加载本身也无法稳定满足 5 分钟。

因此建议：

- 将 GLM/MiniMax 8 卡全量权重、接受率和 GSM8K 用例保留为 model-specific optional/nightly。
- 从 always-on `worker_v2`、`spec_decode_*`、全局 `models/__init__.py` 路由里拆出这些重用例。
- PR 门禁由四卡 K3 dummy smoke 承担；不要把 dummy 输出描述成全量 checkpoint、精度或接受率等价验证。

验收标准应是 A3×4 冷环境连续三次运行，两套 vLLM revision 上每个 nodeid 均 `<300s`，并分别确认 graph replay、两个 DP engine 都产生 drafts、P/D remote blocks/cached tokens 生效。当前没有四卡实跑，所以时间只能作为设计目标，不能先报“已满足”。
