- vLLM 0.23.0 支持 `return_token_ids: true`。
  - 输出 token：`choices[0].token_ids`
  - 输入 token：顶层 `prompt_token_ids`
- 标准 `image_url` data URL 可用。

  `--hf-overrides '{"use_unified_vision_chunk":true,"text_config":{"num_hidden_layers":5}}'`
- 更合理的合入方案是让 `KimiK3Config` 默认设置该字段；修复后验证启动参数应去掉这个临时 override，只保留 5 层设置。

import hashlib

def load(mode, case, repeat):

def digest(ids):
    return hashlib.sha256(
        json.dumps(ids, separators=(",", ":")).encode()
