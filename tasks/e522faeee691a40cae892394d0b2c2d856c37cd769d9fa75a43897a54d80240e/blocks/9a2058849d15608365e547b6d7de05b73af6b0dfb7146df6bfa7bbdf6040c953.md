## 4. Prefix-hit 专属 contingency：cached-block 被 draft context 回写

当前 DSpark context KV 的设计应只写 scheduler 本轮 scheduled tail。对 896/8576/129792 命中，hybrid coordinator 都保留一个未命中的 384-token tail，所以正常不应改写 cached full blocks。

仅当“四平面后 hit 失败、prefix-on unique miss 不失败”时再查这一条：

- 在 draft context precompute 前后只 hash 最后一个 cached full block和首个 tail block；
- 同时记录 per-layer context slot mapping、group ID、physical block ID、plane；
- 不先 dump 全模型。

严格异常判据：cached full block 在 hit 路径被改变，而同 token 的 miss 路径没有；或 context slot 映射落到另一个 group 当前仍持有的 physical block ID。生产 seam 才是 mask cached slots 或对重算 tail 做 COW。现有历史证据不支持先把它当主因。
