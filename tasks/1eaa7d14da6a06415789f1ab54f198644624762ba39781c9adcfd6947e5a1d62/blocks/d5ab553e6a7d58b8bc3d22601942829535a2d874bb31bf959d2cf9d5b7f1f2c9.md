### assistant:final_answer
是**本机一个独立的 Python 后台进程**在轮询，Agent 不参与定时检查。

运行过程是：

1. 启动 VAWS 原生 CLI 或触发已配置的会话 hook 时，自动启动 `workspace_update.py watch`。
2. 进程通过文件锁保证同一仓库只有一个 watcher。
3. 检查主仓最新提交，有变化就同步个人 Fork、准备对应依赖；已准备过则复用。
4. 每轮结束后等待 **300 秒**，再检查。失败时延长重试间隔，最多一小时。

所以准确说是“**每轮完成后隔五分钟检查**”，不是严格整点定时。它不会改正在编辑的目录或替换运行中的环境。

目前没有安装开机自启服务：重启电脑或进程退出后，由下次 VAWS 入口补启动。刚确认本机 watcher 仍在运行，PID 是 `57216`。
