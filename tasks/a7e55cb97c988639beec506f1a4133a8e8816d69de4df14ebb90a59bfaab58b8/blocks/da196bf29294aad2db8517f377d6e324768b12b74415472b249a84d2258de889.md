### DSpark acceptance-rate delta

Acceptance must be calculated from counter deltas around the same workload. The `_created` timestamps and `num_drafts_total` are not acceptance denominators.

```bash
export METRICS_URL="$API_BASE/metrics"

spec_counters() {
  curl -fsS "$METRICS_URL" |
    awk '
      $1 ~ /^vllm:spec_decode_num_draft_tokens_total\{/ {
        draft += $2
      }
      $1 ~ /^vllm:spec_decode_num_accepted_tokens_total\{/ {
        accepted += $2
      }
      END {
        printf "%.0f %.0f\n", accepted, draft
      }
    '
}

read -r accepted_before draft_before < <(spec_counters)

# Run the deterministic validation workload here.

read -r accepted_after draft_after < <(spec_counters)

accepted_delta=$((accepted_after - accepted_before))
draft_delta=$((draft_after - draft_before))

awk -v accepted="$accepted_delta" -v draft="$draft_delta" '
  BEGIN {
    if (draft <= 0) {
      print "No DSpark draft-token delta was recorded." > "/dev/stderr"
      exit 1
    }

    printf \
      "accepted_delta=%d draft_delta=%d acceptance=%.2f%%\n", \
      accepted, draft, 100 * accepted / draft
  }
'
