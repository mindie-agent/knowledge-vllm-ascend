因为 linear 和 RMSNorm 都没有切分，并且逐 token 独立计算：

\[
\operatorname{AllGather}(F(X_r))
=
F(\operatorname{AllGather}(X_r))
\]

其中 \(F\) 可以是完整权重的 linear 或 RMSNorm。RMSNorm 只在 hidden 维归约，AllGather 发生在 token 维，因此数学上等价。

当前 K3 FlashComm 修改也没有改动：

- fused MoE 的路由与 expert map
- routed/shared expert 的计算
- EP 通信后端选择
- expert 输出的归并方式

### assistant:final_answer
只读审计完成。结论是：K3 不需要新增任何手写 pad/unpad；当前应统一复用框架的 token 轴原语。真正需要保留的 K3 特例只有 3D learned residual 的首层布局转换。

数据流如下：

1. `model_runner_v1.py::_pad_for_sequence_parallelism` 已将 token 数补齐到 TP 倍数。
2. K3-VL 即使是纯文本请求，也会由多模态 runner 先构造全量 `inputs_embeds`，所以首层输入是 global `[N,H]`。
3. 首层 KDA/MLA 的 `o_proj` 通过 `SequenceRowParallelOp` reduce-scatter，输出变为 local `[N/TP,H]`。
4. 后续 KDA 在所有投影前调用一次 `maybe_all_gather_and_maybe_unpad` 恢复 global，完成 stateful KDA 后再由 `o_proj` 变回 local。
5. 最后一层由 runner 统一 AllGather。

和现有模型的区别是：

- Qwen3.5 的 GDN 使用融合 `in_proj/qkv_proj`，能直接命中 `SequenceColumnParallelOp` 的 prefix 白名单。
- Kimi K2 的 MLA 已在 MLA wrapper 中处理首层 VL global 输入和后续 Q/KV gather。
- K3 KDA 有独立的 q/k/v/b/f/g 投影，其中还有 `ReplicatedLinear`。因此不能简单把这些名字加入 SequenceColumn 白名单，否则会重复 AllGather 多次，并且仍覆盖不全。当前在 [kimi_kda.py](<redacted:local-path:c0ff1f9817eb>:171) 中一次性 gather 是最小且正确的复用方式，不能删。
- K3 MLA gate 的 `g_proj` 是 head-sharded ColumnParallel，必须先 gather hidden states，再投影；投影后 gather 会把不同 rank 的 head shard 错当成 token 拼接。因此 [mla_v1.py](<redacted:local-path:0c76b8ae5149>:1824) 也需要保留。

必须保留的 K3 特例是 [kimi_k3_text.py](<redacted:local-path:25801955574d>:483)：

```python
block_residual = maybe_chunk_residual(
    attention_output,
    block_residual.squeeze(1),
).unsqueeze(1)
```

首层 learned residual 是 `[N,1,H]`，而 attention 输出已经是 `[N/TP,H]`。它在 post-attention RMSNorm 之前就会参与 learned mix，所以不能像 Qwen/K2 的普通 2D residual 那样等到 RMSNorm 自动处理。这里的 squeeze/chunk/unsqueeze 是必要的，并且仍然复用了框架原语。

不建议直接把 3D residual 传给现有 `maybe_chunk_residual`：其 `F.pad(..., (0,0,0,pad_size))` 是按 2D tensor 编写的，3D 时会补到 block 轴而非 token 轴。当前首层 block 数必为 1，因此 squeeze 方案更安全。

可以做的最小化调整：

- 首层 attention 输出长度改用 Qwen3.5 的 ceil-div，而非当前 floor-div；在 runner 已预补齐时结果相同，但对未补齐或未来 DP 路径更稳健。
- `uses_global_inputs_embeds` 和两处 `is_vl_first_layer` 可以集中为一个静态 predicate，减少重复判断，但不能简单替换成 `is_vl_model`：MM limit 为 0 时 runner 会走 `input_ids`，首层已经是 local。
- `_apply_attention_residual` 末尾的第二次 `maybe_chunk_residual` 在 eager 下首轴相同，是严格 no-op；它只是此前为 Dynamo 动态 SymInt 增加的 shape anchor。建议先保留，等 eager 精度通过后单独验证 ACLGraph 是否仍依赖它。

因此 eager 开关 FlashComm1 若仍有差异，优先检查 row-parallel AllReduce 与 ReduceScatter 的归约顺序、KDA recurrent state 和 MLA gate；AllGather、chunk、pad、unpad 本身只是搬运数据，不会引入数值误差。
