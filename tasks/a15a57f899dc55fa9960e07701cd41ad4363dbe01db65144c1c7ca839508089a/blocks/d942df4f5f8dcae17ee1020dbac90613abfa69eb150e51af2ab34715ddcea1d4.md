### Annotation 1

可以复用。准确地说，不能保留的是之前那版“派生 non-persistent buffer”方案，不是这类优化本身。

- **Qwen3.5 的情况不同**：checkpoint 的 Q/K/V shard 通过专用 loader 直接装入同一个 canonical `conv1d.weight`，forward 只需 `view`，没有第二份需要同步的派生权重。见 [qwen_gdn_linear_attn.py](<<redacted:local-path:b8dd889167fe>/vllm-k3-pr12950-core-d02df/vllm/model_executor/layers/mamba/gdn/qwen_gdn_linear_attn.py:388>)。
- **Kimi KDA** 上游保留三个独立的 FP32 `q/k/v_conv1d.weight`，而 AscendC 接口需要拼接、转置、转换 dtype 后的连续 `[K, 3C]` 权重。这些操作必然产生新存储，不能像 Qwen3.5 那样只做 view。见 [kimi_gdn_linear_attn.py](<<redacted:local-path:b8dd889167fe>/vllm-k3-pr12950-core-d02df/vllm/model_executor/layers/mamba/gdn/kimi_gdn_linear_attn.py:171>) 和当前热点 [kimi_kda.py](<<redacted:local-path:b8dd889167fe>/vllm-ascend-kimi-k3-pr12950-split-stage/vllm_ascend/ops/kimi_kda.py:273>)。
- **DeepSeek MLA 才是可以直接借鉴的范式**：在 `process_weights_after_loading()` 中生成 kernel-format 权重，并通过 `replace_parameter(..., prefer_copy=True)` 原地更新，既让派生权重成为正式 Parameter，又保持 ACLGraph 捕获后的 `data_ptr` 不变。见 [mla_attention.py](<<redacted:local-path:b8dd889167fe>/vllm-k3-pr12950-core-d02df/vllm/model_executor/layers/attention/mla_attention.py:967>) 和 [replace_parameter](<<redacted:local-path:b8dd889167fe>/vllm-k3-pr12950-core-d02df/vllm/model_executor/utils.py:47>)。

旧方案出问题的原因也很明确：main 的 kernel-format reload 使用 `model.get_parameter(name)`，代码中甚至留着 `TODO: buffers?`；因此 buffer 天然不会参与这种 reload。见 [gpu_model_runner.py](<<redacted:local-path:b8dd889167fe>/vllm-k3-pr12950-core-d02df/vllm/v1/worker/gpu_model_runner.py:5574>)。

Kimi 最合适的实现应当是：

1. 保留三个 q/k/v 权重作为 checkpoint-format canonical Parameter。
2. 在模型权重加载完成时生成一个 packed kernel-format Parameter。
3. 后续 checkpoint-format reload 重新计算并通过 `prefer_copy=True` 原地刷新。
4. kernel-format direct reload 直接传输这个具名 packed Parameter。
5. forward 只读取 packed Parameter，不再执行 `transpose + cat + dtype cast + contiguous`。
6. 不修改 AscendC kernel，也不需要 Model Runner V2。

Kimi GDN 不属于通用 loader 当前自动处理的 `Attention/MLAAttention` 类型，因此触发 post-load 时需要沿用仓库已有的 quant-method wrapper 惯例，而不是新增全局生命周期或打 ModelRunner patch。

所以结论是：**这个优化可以做，并且应该按 DeepSeek 的 Parameter 生命周期重写；之前放弃的只是 buffer 版本。** 按你的顺序，它仍作为主 PR 完整验证后的独立 commit，并补齐 main/v0.25.1、checkpoint reload、kernel-format reload 和 ACLGraph 地址稳定性测试。
