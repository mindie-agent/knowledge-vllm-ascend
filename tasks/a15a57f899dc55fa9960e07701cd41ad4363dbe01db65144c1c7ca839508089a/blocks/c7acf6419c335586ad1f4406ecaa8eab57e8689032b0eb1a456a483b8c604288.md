```python

    {"quant_mode": self.deepep_output_dtype.value}
    if _is_npu
    else {}

```

修复后保持：

```text
--deepep-mode auto
--deepep-dispatcher-output-dtype auto
```

target W4A8 会得到 `int8`，unquant draft 保持 `bf16`。不要全局指定 dispatcher `int8`，否则会同时污染 unquant draft。

如果坚持零源码修改，只能做有限正确性旁路：

```text
--deepep-mode low_latency
--chunked-prefill-size 512
--max-running-requests 16
```
