### 指标语义

- `num_drafts`：执行了多少轮非空 speculative draft。
- `num_draft_tokens`：这些轮次实际提出的 draft token 总数。
- `num_accepted_tokens`：目标模型接受的 draft token 数；不包含 bonus token。
- `accepted_tokens_per_pos[position=i]`：至少连续接受到第 `i+1` 个 draft token 的轮次数。

因此：

```text
D = Δnum_drafts
T = Δnum_draft_tokens
A = Δnum_accepted_tokens
P[i] = Δnum_accepted_tokens_per_pos[i]

mean_draft_width       = T / D
draft_acceptance_rate  = A / T
mean_acceptance_length = 1 + A / D
per_position_rate[i]   = P[i] / D
```

硬性恒等式：

```text
A = P[0] + P[1] + ... + P[6]
1 >= P[0]/D >= P[1]/D >= ... >= P[6]/D >= 0
```

GQA DSpark 固定 `block_size=7` 时，`T/D` 应接近或等于 7。

### Reset 和差分规则

- `/reset_prefix_cache` 不会重置 DSpark Prometheus Counter。
- `SpecDecodingLogging.reset()`只清日志输出窗口，也不重置 Prometheus Counter。
- 没有适合本测试使用的 HTTP metrics-reset endpoint。
- Counter 通常只在 API/logger 进程重建时归零；elastic DP 扩容也会重建 logger。
- 正确方法是同一进程内保存 before/after，并检查：
  - `drafts_created` 未变化；
  - after 中所有 Counter 不小于 before；
  - 测量窗口没有其他请求；
  - workload 完成后再抓 after。

有限 benchmark 应使用直接 Counter 差分，不用 PromQL `rate()`。

### 可靠的 DP1 计算命令

先保存快照：

```bash
BASE_URL=http://127.0.0.1:18077
RESULT_DIR=/path/to/owned-result-dir
mkdir -p "$RESULT_DIR"

curl -fsS "$BASE_URL/metrics" > "$RESULT_DIR/metrics-before.prom"

# 在这里运行且只运行待测请求。

curl -fsS "$BASE_URL/metrics" > "$RESULT_DIR/metrics-after.prom"
```

分析函数不依赖标签排列顺序：

```bash
ENGINE=0
MODEL=kimi-k3-w4a8-dspark
BEFORE="$RESULT_DIR/metrics-before.prom"
AFTER="$RESULT_DIR/metrics-after.prom"

counter_value() {
  local name="$1"
  local file="$2"
  local position="${3:-}"

  awk \
    -v name="$name" \
    -v engine="$ENGINE" \
    -v model="$MODEL" \
    -v position="$position" '
      $1 ~ ("^" name "\\{") &&
      index($1, "engine=\"" engine "\"") &&
      index($1, "model_name=\"" model "\"") &&
      (position == "" ||
       index($1, "position=\"" position "\"")) {
        value += $2
      }
      END { printf "%.0f\n", value + 0 }
    ' "$file"
}

raw_value() {
  local name="$1"
  local file="$2"

  awk \
    -v name="$name" \
    -v engine="$ENGINE" \
    -v model="$MODEL" '
      $1 ~ ("^" name "\\{") &&
      index($1, "engine=\"" engine "\"") &&
      index($1, "model_name=\"" model "\"") {
        print $2
        found = 1
      }
      END { if (!found) exit 1 }
    ' "$file"
}
```

读取并校验进程连续性：

```bash
created_before="$(
  raw_value vllm:spec_decode_num_drafts_created "$BEFORE"
)"
created_after="$(
  raw_value vllm:spec_decode_num_drafts_created "$AFTER"
)"

awk -v before="$created_before" -v after="$created_after" \
  'BEGIN { exit !(before == after) }' ||
  {
    echo "INVALID: Prometheus logger restarted during the run" >&2
    exit 1
  }
```

计算三个主 Counter：

```bash
drafts_before="$(
  counter_value vllm:spec_decode_num_drafts_total "$BEFORE"
)"
drafts_after="$(
  counter_value vllm:spec_decode_num_drafts_total "$AFTER"
)"
tokens_before="$(
  counter_value vllm:spec_decode_num_draft_tokens_total "$BEFORE"
)"
tokens_after="$(
  counter_value vllm:spec_decode_num_draft_tokens_total "$AFTER"
)"
accepted_before="$(
  counter_value vllm:spec_decode_num_accepted_tokens_total "$BEFORE"
)"
accepted_after="$(
  counter_value vllm:spec_decode_num_accepted_tokens_total "$AFTER"
)"

drafts=$((drafts_after - drafts_before))
draft_tokens=$((tokens_after - tokens_before))
accepted=$((accepted_after - accepted_before))

if (( drafts <= 0 || draft_tokens <= 0 || accepted < 0 )); then
  echo "INVALID counters: drafts=$drafts draft_tokens=$draft_tokens accepted=$accepted" >&2
  exit 1
fi

awk \
  -v drafts="$drafts" \
  -v draft_tokens="$draft_tokens" \
  -v accepted="$accepted" '
    BEGIN {
      printf "drafts=%d\n", drafts
      printf "draft_tokens=%d\n", draft_tokens
      printf "accepted_tokens=%d\n", accepted
      printf "mean_draft_width=%.6f\n", draft_tokens / drafts
      printf "draft_acceptance_rate=%.6f\n",
             accepted / draft_tokens
      printf "mean_acceptance_length=%.6f\n",
             1 + accepted / drafts
    }
  '
```

逐位置：

```bash
per_pos_sum=0

for position in 0 1 2 3 4 5 6; do
  before="$(
    counter_value \
      vllm:spec_decode_num_accepted_tokens_per_pos_total \
      "$BEFORE" \
      "$position"
  )"
  after="$(
    counter_value \
      vllm:spec_decode_num_accepted_tokens_per_pos_total \
      "$AFTER" \
      "$position"
  )"
  count=$((after - before))

  if (( count < 0 )); then
    echo "INVALID negative position delta: position=$position" >&2
    exit 1
  fi

  per_pos_sum=$((per_pos_sum + count))
  awk -v p="$position" -v count="$count" -v drafts="$drafts" \
    'BEGIN {
       printf "position_%d accepted=%d rate=%.6f\n",
              p, count, count / drafts
     }'
done

if (( per_pos_sum != accepted )); then
  echo "INVALID invariant: per_pos_sum=$per_pos_sum accepted=$accepted" >&2
  exit 1
fi
```
