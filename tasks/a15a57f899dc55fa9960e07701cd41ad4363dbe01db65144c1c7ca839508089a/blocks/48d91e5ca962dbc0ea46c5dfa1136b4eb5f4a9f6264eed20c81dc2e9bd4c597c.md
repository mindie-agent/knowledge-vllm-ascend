结论：734 A/B 不能只把 FIA 的 `actual_seq_lengths_kv` 加 7。安全的最小方案应同时完成三件事：

1. Scheduler 将 legacy Kimi K3 DSpark 的 lookahead 从 7 扩到 14。
2. Proposer 将 draft FIA 的 KV 长度从 `context+7` 改为 `context+14`。
3. 对额外的 7 个 KV slot 逐层显式写零，不能依赖缓存初始状态。

静态依据已经很明确：

- SGLang `dspark_draft.py::_run_forward` 先设置 `draft_seq_lens_cpu = batch.seq_lens_cpu + 7`。
- Ascend draft backend 在 `TARGET_VERIFY` 下又加 7。
- 因而 FIA 最终拿到的是 `context+14`。
- SGLang MHA KV pool 通过 `torch.zeros` 初始化；720-token 样例中 727–733 与 query 仍在同一 128-token 页，未写位置因此为零。
- 但这属于实现行为，不应假定 vLLM 的空闲物理块或复用缓存也为零。

建议注入点：

- `vllm_ascend/patch/platform/patch_dspark_scheduler.py`
  - 包装 `Scheduler.__init__`。
  - exact legacy config 且 A/B 模式非 `off` 时，将 `self.num_lookahead_tokens` 从 7 改为 14。
  - `round0` 模式也必须全程预留 14，因为 scheduler 不知道 worker 当前 draft 轮次。

- `vllm_ascend/spec_decode/dspark_proposer.py`
  - `initialize_attn_backend()`：为每个 draft KV group 建立额外尾 slot buffer。
  - `set_inputs_first_pass()`：
    - query 仍为 `context ... context+6`；
    - 尾部位置为 `context+7 ... context+13`；
    - `cad.seq_lens = effective_seq_lens + 14`；
    - 根据各 group 的 block table 生成尾 slot mapping。
  - `build_draft_attn_metadata()`：
    - 显式用上述 `cad.seq_lens` 覆盖每个 draft metadata 的 `seq_lens`、`seq_lens_cpu`、`seq_lens_list`。
    - 这是必要的，因为通用 builder 可能优先读取旧的 CPU mirror。
  - `build_model_inputs_first_pass()`：
    - 先调用父类写 context KV；
    - 再对额外 7 个 slot 逐层写零；
    - 随后才进入 query forward，后者写入正常的 7 个 query KV。

建议数据结构：

```python
_per_group_kv_tail_slot_mapping_buffers: dict[int, torch.Tensor]
_kv_tail_slot_mappings_by_layer: list[torch.Tensor]
_kv_tail_zero_buffers: list[tuple[torch.Tensor, torch.Tensor]]
_dspark_kv_tail_mode: Literal["off", "round0", "all"]
_dspark_kv_tail_round: int
_dspark_kv_tail_active: bool
```

尾 slot 应按每个 group 的真实 block size 计算：

```python
tail_positions = effective_seq_lens[:, None] + arange(7, 14)
block_numbers = tail_positions // block_size
block_ids = block_table[:batch].gather(1, block_numbers)
tail_slots = block_ids * block_size + tail_positions % block_size
```

不要清零整个物理块，只清零这 7 个准确 slot，否则可能破坏同页 context、query 或共享前缀。

- target `model_type == "kimi_k3"`
- draft `model_type == "qwen3"`

模式建议放在 `additional_config`，默认 `off`。四机接收率比较使用 `all`；`round0` 只用于首轮数值定位。
