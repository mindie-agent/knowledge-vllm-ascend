### Annotation 1

结论：**当前定位到的 backing collision 只影响 GQA DSpark；K3 MLA DSpark 不受这一具体问题影响。** 但根因本质是“共享 backing 的 KV layout/stride 不兼容”，并非机制上限定 GQA。

- GQA draft：每个 block 为 `98,304 B`
- K3 target MLA：每个 block 为 `442,368 B`
- K3 MLA draft：同样为 `442,368 B`

GQA draft 与 target 共享 backing、却按不同紧凑 stride 映射 block，才会让不同 scheduler block ID 落到同一物理区域。MLA draft 与 target 都是 `(kv_lora_rank=512, rope_dim=64)`，物理映射一致；RoPE/NoPE 差异不会改变缓存布局。
