实际调用链是：

```text

  -> torch_npu.npu_fused_infer_attention_score_v2
```

编译 ops-transformer 不会把 `torch_npu` Python 包替换成“vllm-ascend 的 FIA”；vllm-ascend 本身也不包含 FIA kernel。`torch_npu==2.10.0.post2` 里的 op-plugin wrapper 仍然存在，只是通过 `ASCEND_CUSTOM_OPP_PATH` 让 CANN runtime 选择编译出来的自定义 FIA OPP。
