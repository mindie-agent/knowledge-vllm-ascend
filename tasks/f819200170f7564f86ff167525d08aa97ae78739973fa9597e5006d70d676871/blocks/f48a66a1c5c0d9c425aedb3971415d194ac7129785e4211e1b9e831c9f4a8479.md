```text
当前：
GMM1 → BF16 → SiTU → DynamicQuant → GMM2

目标：
GMM1(INT32)
  → DequantSituQuant(
      per-expert weight_scale/bias,
      per-row activation_scale,
      group_index)
  → INT8 + per-row scale
  → GMM2
```

影响主要是：

- DequantSituQuant 输入从当前 INT8 语义变成 GMM1 的 INT32 累加结果。
