  - B_hit/B_cold tokens 均为 `[99633, 133112, 77417]`

  - cumulative logprob 差：`0.0`
  - 每步 top-20 token、rank、logprob 全部一致，20/20 overlap
  - Cache-on eager 与 FULL_DECODE_ONLY 的 A/B 输出也逐值一致

但发现一个独立精度风险：fresh cache-off 会切到 `mamba_cache_mode=none`，输出与 cache-on/`align` 不同；甚至首条未命中的 A 也不同。Cache-on eager 与 cache-on graph 在不同 fresh engine 间完全一致，因此不是普通初始化随机性。现象更符合 KDA 在：

- `align`：按 768-token state boundary 分段 continuation
- `none`：1539-token 整段 prefill

之间存在 chunk/state continuation 语义差异。

所以可以确认 prefix hit、state restore、reset 后 cold 重算及 FULL_DECODE_ONLY replay 本身精度正确；但 `align` 与 `none` 的长 prefill parity 需要作为独立问题继续排查，当前不应宣称 cache-on/off 跨模式等价。
