### user
git是开源的么


### assistant:final_answer
是的，**Git 是免费开源的分布式版本控制系统**，采用 **GNU GPL v2** 许可证，你可以查看、使用和修改它的源代码。

顺便区分：**Git 是版本管理工具，GitHub 是托管 Git 仓库的平台**，两者不是同一个东西。
