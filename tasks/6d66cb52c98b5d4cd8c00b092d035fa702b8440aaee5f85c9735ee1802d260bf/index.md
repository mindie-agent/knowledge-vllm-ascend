# Git 开源性与 Git/GitHub 区分

当前材料说明 Git 使用 GNU GPL v2、属于免费开源的分布式版本控制系统，并强调 Git 与 GitHub 的用途不同。原始材料仅覆盖这一说明，未提供其他上下文、修正或未完成结果。
