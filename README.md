# MindIE Agent · vLLM-Ascend knowledge

Public domain content belongs here. Keep a Markdown title and body, original sources,
applicable conditions and uncertainty; remove private endpoints, paths and credentials.
CI checks Markdown and redaction using a fixed engine revision. Human reviewers decide merges.
Experience is advisory material, and publication does not certify factual correctness or reproduction.

The current live publisher still writes the verified feed to
[mindie-agent/knowledge, knowledge/vllm-ascend](https://github.com/mindie-agent/knowledge/tree/knowledge/vllm-ascend).
Consolidating that feed here and binding consumers is the next content migration.
The former OVPack release workflow is removed; there is no parallel legacy distribution channel.

Existing notes and immutable source provenance remain under `corpus/`.
Runtime code and the new collection/distribution/judge loop belong to
[knowledge](https://github.com/mindie-agent/knowledge), and Codex setup belongs to
[mindie-agent-codex](https://github.com/mindie-agent/mindie-agent-codex).
