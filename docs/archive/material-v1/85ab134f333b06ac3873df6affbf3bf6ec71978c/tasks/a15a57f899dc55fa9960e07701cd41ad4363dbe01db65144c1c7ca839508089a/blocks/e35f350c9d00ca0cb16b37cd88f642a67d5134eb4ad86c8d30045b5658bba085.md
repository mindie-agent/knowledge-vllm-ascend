- Legacy GQA draft 的 `config.json` 不含量化声明。显式 `method=dspark` 时，`draft_model_config.quantization=None`，各 draft Linear 通过 `get_draft_quant_config()` 得到的也是 `None`。因此 4.2 GiB Qwen3 draft 按 BF16 加载，不会套用 Ascend/ModelSlim 量化。

因此当前 GQA 精度/接收率问题不应归因于 draft 错量化或该 list 的 host OOM。
