接收率口径已确认：

- vLLM 的 `num_accepted_tokens` 只计被接受的 draft tokens。
- `mean_acceptance_length = 1 + accepted_drafts / verification_rounds`。
- 其中 `+1` 是每轮 target 输出的 token；不是 DSpark anchor。
- 因此模型卡 `5.666` 等价于平均接受 `4.666` 个 draft token，K=7 时固定宽度接收率为 `66.657%`。

工程区间 `AL 5.1–6.2` 可换算为 `58.57%–74.29%`，但模型卡没有方差或置信区间，所以这只能作为工程排障带，不能称为官方正常区间。
