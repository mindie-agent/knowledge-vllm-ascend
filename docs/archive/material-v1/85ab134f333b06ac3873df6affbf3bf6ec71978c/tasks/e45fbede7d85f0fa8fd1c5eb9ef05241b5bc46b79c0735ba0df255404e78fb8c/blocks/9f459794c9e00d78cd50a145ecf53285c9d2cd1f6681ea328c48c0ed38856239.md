触发链路：

- HMA no-CP 路径会为每个 D TP rank 合并 MLA 与 Mamba 的目标 P rank；未落在同一 P rank 时产生额外 port task：[mooncake_connector.py](<redacted:local-path:db1d7ea85003>:2697)。
- 每个 task 完成都会发送一个 `DONE_RECVING_MSG`：[mooncake_connector.py](<redacted:local-path:db1d7ea85003>:751)。

- P listener 已支持按 request 累计 DONE，达到本地 port 的期望次数后才报告完成：[mooncake_connector.py](<redacted:local-path:db1d7ea85003>:365)。
