仍需 `OnlineRenderer.render_chat` 的单个窄 adapter，原因是当前 vLLM 接口边界：

- `OnlineRenderer.render_chat(self, request: ChatCompletionRequest, *, skip_mm_cache=False)` 是最后一个持有完整 typed request 的公开入口。
- `BaseRenderer.render_messages[_async](messages, params: ChatParams)` 只收到消息和 `ChatParams`。
- `ChatParams` 不包含 typed `tool_choice`、named-tool choice 和 `response_format`；`build_chat_params()` 也没有完整传递这些字段。
- K3 tokenizer encoder需要这些信息来区分 `auto/required/named/none`、过滤 named tool，并传递 response format。
- 因此无法仅靠 `KimiK3Renderer/BaseRenderer` 无损完成映射，除非上游扩展 `ChatParams` 或增加正式 request-adapter hook。

当前 adapter 只在 `self.renderer` 是 `KimiK3Renderer` 时生效，显式安装，使用 `wraps` 保持上述签名；不再修改任何 OpenAI serving 私有方法。
