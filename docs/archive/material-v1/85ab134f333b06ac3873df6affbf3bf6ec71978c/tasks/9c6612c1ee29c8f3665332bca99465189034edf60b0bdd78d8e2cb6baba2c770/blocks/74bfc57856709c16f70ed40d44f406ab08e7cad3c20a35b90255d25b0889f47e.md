### 可直接上屏的定位过程

| 轮次 | Agent 做什么 | 结果怎样改变判断 |
|---|---|---|
| 初始现象 | 4 机 64 卡，128K 请求，并发 2 | 请求成功、采信率 100%，但输出全部是 `!` |
| 找触发条件 | 固定输入，只切换 Cache、冷启动/复用、单并发/多并发 | 问题集中在 Cache 复用与并发同时出现时 |
| 缩小复现 | 固定 token ID 和输入 hash，将 128K 缩到 896 token | 异常仍然存在，长输入不再是必要条件 |
| 判断执行顺序 | 其他条件不动，只增加一次完整等待 | 输出恢复，排查重点转到“写入和读取的先后关系” |
| 定向采样 | 只采异常位置前后的数值摘要 | 主模型 Layer 23 首次出现 448 个 NaN，Layer 24 开始扩散 |
| 多卡确认 | 对齐同一组 16 张卡的结果 | 16 张卡变化一致，单卡掉队不再是主要方向 |

### 推荐口播
