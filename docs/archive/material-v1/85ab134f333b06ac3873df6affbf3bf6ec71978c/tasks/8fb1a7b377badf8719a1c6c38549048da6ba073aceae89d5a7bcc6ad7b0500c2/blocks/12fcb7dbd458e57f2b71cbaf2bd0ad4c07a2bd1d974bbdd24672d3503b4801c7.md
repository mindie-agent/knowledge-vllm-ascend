| 原则 | 具体结论与依据 |
|---|---|
| 1 总成本 | 单次读取只打开指定块；热检索与翻页复用派生索引；重基复用已有块索引，没有新增模型调用、服务或审批。 |
| 2 封闭问题 | 工具只处理规范引用、当前成员关系、查询词覆盖、确切版本和文件身份；没有把经验真实性或适用性判断机械化。 |
| 3 理解负担 | 读取入口统一为 `ref`，返回相邻块导航；工具直接提供独立 `feedback_ref`，不用调用者自行拼接 revision 或管理分页偏移。 |
| 4 职责边界 | Markdown 保持正文权威；SQLite 新增内容仅为身份与操作回执；ReMe 保存可重建的检索数据。发布声明是数据，消费者不会据此加载贡献中的代码。 |
| 5 Skill 信息性 | `curate-knowledge` 仍限显式维护，新增内容解释引用及错误语义；没有增加强制查询、反馈、整理或收尾流程。 |
| 6 知识参考性 | 引用分组明确是导航；引用数量不增加分数或置信度。失败复用保留自己的摘录，历史引用不冒充当前正文，导航与摘要继续标注为可错元数据。 |
| 7 按需介入 | 查询和读取不触发模型、发布或新授权；沿用既有 admission、sharing 和后台恢复边界，没有新增跨 session 激活。 |
| 8 成果复用 | 续写采用已确认 main 加可证明未发送的块；保留已完成索引、冻结包和不确定发送状态；更新 open PR 仍校验其实际 head。 |
| 9 错误可见 | `material_corrupt`、引用失效、withdrawal 与 continuation 错误分别返回；发布契约不匹配在发送意图前失败，保留原数据和冻结材料；缺失 prepared receipt 明确失败，不猜测基线。 |
