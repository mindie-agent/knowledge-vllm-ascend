发现两个应该先修的实际问题：

- **配置归属依赖脚本所在目录。** 从 worktree 对母仓运行配置预览，生成的 MCP 入口仍指向 worktree。应该由工具自动解析稳定归属，不能靠新增“先切回母仓”的操作要求解决。
- **初始化指引和探测有过时部分。** `--compact` 仍执行完整探测；Fork 探测按同名仓库拼接，可能漏掉改名的个人 Fork；知识重试说明还包含缺少必填参数、且不一定需要执行的客户端重配命令。

更合适的信息分工是：

- **AGENTS：** 始终需要知道的少量规则和入口。
- **Hook／工具结果：** 当前 worktree、身份、版本，以及失败在哪里。
- **Skill：** 按需提供判断方法。
- **文档／知识库：** 按需查细节和经验。
