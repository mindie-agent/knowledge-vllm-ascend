### assistant:final_answer
对。更准确地说，**TH 是逻辑布局/shape**，表示二维 Tensor `[T, H]`：

- `T`：RoPE position/token 行数（这里是完整 RoPE cache 的行数，并非当前 batch token 数）
- `H`：RoPE/head dimension，**不是模型的 hidden_size**

`compressor_metadata` 的 `rope_cos`、`rope_sin` 明确要求二维输入，非二维会直接报错：[torch_binding.cpp](<redacted:local-path:ec13566b382a>:898)。Python 调用前也会把原始 RoPE cache reshape 成 `[shape[0], shape[-1]]`：[compressor.py](<redacted:local-path:367d981baf26>:180)。

需要区分两件事：

- 算子注册里的物理 `Format` 是通用的 `FORMAT_ND`：[compressor_metadata_def.cpp](<redacted:local-path:c841eac0dbcb>:12)
- TH 是基于 shape 的逻辑含义 `[T, H]`

另外，`compressor_metadata` 生成的 `compress_cos/sin` 是 `[T_compressed, 1, 1, H]`，下游再 view 成 TH；而 `compressor` 主算子的 `x` 本身同时支持 TH 和 BSH：[compressor_tiling.cpp](<redacted:local-path:dbd95e083215>:54)。
