# [RFC]: Kimi K3 Roadmap

### 📌 Current Status

Initial Kimi K3 support has landed in `releases/v0.26.0rc` through [#12950](https://github.com/vllm-project/vllm-ascend/pull/12950).

The current baseline includes the KDA/MLA model architecture, KDA and SiTU operators, quantized MoE execution, multimodal processing, GQA DSpark, PD disaggregation, ACLGraph, reasoning, and tool calling.

This RFC tracks the remaining work required to bring Kimi K3 support to `main` and improve its feature coverage and performance on Ascend A2, A3, and A5.

### 🧭 Roadmap
#### vLLM Framework Features
- [ ] Support shared-expert DP and multistream overlap for shared experts
- [ ] Support multistream overlap for KDA gating, and QKV computation.
- [ ] Support dynamic chunked pipeline parallelism.
- [ ] Support GQA/MLA DSpark for Kimi K3.
- [ ] Support dynamic EPLB with online expert-load collection and redundant-expert adjustment.
- [ ] Support MXFP4/MXFP8 quantization for shared-expert
- [ ] Support A2/A3 INT4 W4A8C16 and W4A8C8 quantization, including INT8 shared experts and KV cache.
- [ ] Support MLA KV offload to host DDR or SSD during prefill and decode.
- [ ] Support runtime routed-expert weight offload on A5.


#### Operators
- [ ] Enhance MLA operators with optional RoPE, head-count generalization, FlashDecoding, C8 quantization, and non-contiguous KV cache.
- [ ] Enhance KDA operators with prefix-aware `causal_conv1d`, gate cumulative-sum, chunk/recurrent KDA, non-contiguous state, attention-residual fusion, and delta-gated fusion.
- [ ] Support `DequantSituQuant` and MegaMoE SiTU execution on A3 and A5, including batch-size generalization and large-scale EP.

#### Serving and PD Disaggregation
- [ ] Improve PD disaggregation with DP-aware proxy load balancing, unequal-TP transfer, PP-aware transfer, and layerwise/cross-layer hybrid-state transfer.
- [ ] Support KDA/MLA hybrid cache pooling through Memcache, Mooncake, and compatible KV-pool connectors.
