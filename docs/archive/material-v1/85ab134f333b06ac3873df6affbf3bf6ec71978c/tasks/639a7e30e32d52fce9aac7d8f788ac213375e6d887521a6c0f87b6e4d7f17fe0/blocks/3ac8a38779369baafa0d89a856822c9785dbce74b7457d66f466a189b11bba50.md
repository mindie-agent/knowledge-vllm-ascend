P0

- 多网卡通信 IP 未固定。`launch-k3-dspark-temp.sh:91-96` 设置了 HCCL 网卡，但没有设置 `VLLM_HOST_IP`。Mooncake 在 `mooncake_connector.py:1640-1643, 2029` 用 `get_ip()` 发布 scheduler/worker 的握手地址；`network_utils.py:33-52` 未配置时按默认路由猜测 IP，可能发布管理网、bridge 或不可达地址。最小修正：显式设置 `VLLM_HOST_IP=178.27.4.${ip}`，并在启动前验证可绑定及四机互通。vLLM 官方也要求多网卡多节点分别设置此变量。[vLLM 环境变量说明](https://docs.vllm.ai/en/latest/configuration/env_vars/)

- 现有脚本不支持“精确 PGID 清理”。base `:115` 和 PD `:63` 虽然最终 `exec`，但没有创建独立 session，也没有记录 PID、PGID、starttime。不能复用 `SERVICE_RUNBOOK.md:309-336`：`:315` 的模型路径 `pkill` 会命中同 target 的其他服务，`:332-335` 会杀容器内所有 `VLLM::`。最小方案：每个 node/role 用独立 `setsid` 启动，记录 PID、PGID、starttime、完整命令；停止前复核 model、port、`--data-parallel-start-rank`，只 `TERM -- -PGID`，再复核端口和 NPU。
