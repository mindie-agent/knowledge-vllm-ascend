建议锁定以下约束：

- `cites` 是块级派生信息，只来自规范引用或可信工具回执，含义仅为“引用了”，不表示原创、验证或独立证据。无需写进正文。
- 同一可解析来源链，只有来源正文也匹配当前查询时才归组。匹配不能来自拼接的摘要/导航；可要求来源正文匹配的 query token 覆盖衍生块的匹配 token，避免一个公共词就吞掉新观察。
- 原文是组的来源锚点；组内修正、反例、失败记录仍按查询相关性显示自己的 excerpt 和可读 block ref。禁止只返回原文加 `related_count`。
- `limit` 按组计，相关命中可分页。精确 task/block ref 查找不能被归组改成另一个目标。
- 多源、环、缺失、跨域不强行推导“共同根”，保持普通结果和引用提示。格式合法但目标退役可以 unavailable；磁盘读取、校验失败必须报错。
- block ref 绑定 `block_id + 文件 hash`，读取时必须仍是当前 manifest 的成员；task 追加不使已有 block ref 失效。合法替换/撤回是 superseded/unavailable，文件损坏是 error。

任务包与 Bot 维护应共用一套机械包操作：

1. 改标题、摘要或导航，只改 manifest 并重算绑定。
2. 修正文，生成新 block ID、替换 manifest 引用并删掉旧当前文件；不能同 ID 改不可变正文。
3. 撤回整任务，删除整个包；普通检索退出，旧引用解释为已不可用。
4. 生产者后续续接，以已确认的远端包为基线，只追加本地未发送的新块，保留 Bot 修改；未知写入先核对。
